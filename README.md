# Echoes-of-Ancient-Egypt

This project aims to classify Egyptian hieroglyphs, contributing to historical research and helping people unfamiliar with this ancient writing system identify its symbols. We will compare an MLP baseline, a CNN, and pretrained VGG16 using transfer learning. Through this project, we also hope to gain a deeper understanding of how AI models learn, process images, and make predictions.
